## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chat/webview actions -> orchestrator mutation layer | User inputs can mutate approval state and scope |
| free-text comments -> revision targeting | Untrusted text influences scenario regeneration candidates |
| approved scope selector -> generation stage handoff | Incorrect selector can include rejected scenarios |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | T | `orchestrator.ts` scenario actions | mitigate | Accept only typed action envelopes, enforce state guard checks before mutation |
| T-03-08 | R | approval/revision history | mitigate | Persist timestamped action history entries with actor/source (`chat`/`webview`) and requestId |
| T-03-09 | E | bulk override path | mitigate | Keep bulk default `pending_only`; require explicit `force_override` in payload and log override event |
| T-03-10 | I | free-text comment handling | mitigate | Classify and sanitize comment text; never treat raw text as executable selector expression |
</threat_model>
