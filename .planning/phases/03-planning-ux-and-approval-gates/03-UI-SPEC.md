## Visual Hierarchy Contract

Primary focal point and eye-order for plan review surface:
1. Scenario status chips and state counts (`pending`, `approved`, `rejected`, `needs_revision`)
2. Primary approve CTA in sticky bulk-action bar (`Approve Selected Scenarios`)
3. Revision comment affordance (per-scenario + global comment entry points)

---

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Approve Selected Scenarios |
| Empty state heading | No scenarios in this view |
| Empty state body | Try another group tab or add revision feedback to regenerate targeted scenarios. |
| Error state | Plan review state is out of sync. Refresh panel or run quick action `continue`/`cancel` in chat to resync. |
| Destructive confirmation | Reject scenario: "Move this scenario to Needs Revision?"; Reject all pending: "Reject all pending scenarios? Approved and already-rejected items stay unchanged."; Cancel run: "Cancel this planning run? Approval session will close." |
