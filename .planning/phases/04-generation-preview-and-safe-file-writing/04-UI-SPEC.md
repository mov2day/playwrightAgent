## Interaction Contract

| Area | Contract |
|------|----------|
| Preview surfaces | Every preview render appears in both chat and webview from one canonical payload (source: D-05, D-07). |
| Preview payload shape | Must include structured summary + unified patch diff; summary-only or raw-patch-only views are invalid (source: D-07). |
| Global write gate | File writes unlock only after one explicit approve-all decision on current preview version (source: D-06). |
| Action vocabulary | Gate actions use exact vocabulary: `approve`, `reject`, `continue`, `cancel` plus optional free-text comments (source: D-15). |
| Re-approval trigger | Any comment/regeneration that changes generated content invalidates old approval and requires fresh global approval (source: D-08). |
| Scope integrity | Preview and generation must contain approved scenarios only; rejected scenarios never enter payload or writes (source: `GEN-01`, D-01..D-02). |
| Mixed write outcomes | UI must show per-file outcomes: `patched`, `created`, `skipped` with reason for each skipped target (source: D-11). |

## Write Safety Contract

| Rule | Required Behavior |
|------|-------------------|
| Anchors unsafe | Do not modify target file when anchor confidence is unsafe/absent; fallback to new scoped file (source: D-09). |
| Marker identity | Generated blocks use stable per-scenario marker IDs so regenerate/write updates same block without duplication (source: D-10). |
| No-delete mode | Never delete existing user-authored tests/blocks; only append or replace generated marker blocks (source: D-12). |
| Retry scope | Single auto-fix retry may edit only generated/updated files from this run (source: D-13). |
| Retry failure | Block execution, show structured failure bundle, and wait for user decision via gate actions (source: D-14, D-16). |

---

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Approve All Changes |
| Empty state heading | No generated changes ready for preview |
| Empty state body | Approve scenarios or add revision comments, then regenerate to produce a new preview bundle. |
| Error state | Write blocked: lint/type checks failed after one auto-fix attempt. Review failure summary and choose `continue`, `reject`, or `cancel`. |
| Destructive confirmation | Reject change set: "Reject this generated change set and keep repository files unchanged?"; Cancel run: "Cancel this generation run? Pending generated changes will not be written." |
