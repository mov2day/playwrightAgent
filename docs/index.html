Built for teams that need control before automation.

The extension is not a blank test generator. It is a governed orchestration layer for repo analysis, ticket context, review, generation, and local execution.

Approval workflow

Three blocking gates keep ownership with the team.

Confidence stop before plan generation Per-test plan approval Generated diff review before writes Execution after explicit acceptance
Secret boundary

Credentials stay local.

Jira and Confluence access run through local tooling and environment variables. Prompt context gets the findings, not the keys.

Repo fidelity

Production output

Directly runnable output, not speculative test prose.

Generated scripts are shaped to local conventions, previewed before writes, then executed through the repo’s own Playwright runner for final feedback.

A controlled path from requirement to runnable spec.

Each stage narrows risk. Context gets fused, confidence gets scored, humans approve the plan, then the extension writes and runs only what survives review.

Scan

Read repo shape

Detect stack, fixtures, folder patterns, and reusable test primitives on current workspace state.

Collect

Pull ticket context

Traverse Jira hierarchy, search Confluence, and merge direct user context without passing secrets into prompts.

Score

Decide confidence

Hard-stop low-confidence runs and surface exactly what is missing before any speculative generation starts.

Approve

Review each plan

Use a tabbed review surface to accept or reject each proposed test before generation and file writes.

Run

Write and execute

Preview diffs, update files surgically, then run the resulting tests locally and report what passed or failed.
